PROVA PRÁTICA: Finalizar cadastro e login de usuário

Instruções
Utilizar projeto da atividade anterior e finalizar todo o fluxo de cadastro, login e edição de um usuário.

O que precisa ter:
Tela inicial com dois botões, botão de LOGIN e o botão de CADASTRO;
Tela de cadastro;
Tela de login;
Tela de edição de usuário;
Só conseguir entrar na tela de edição quando estiver logado;
Tem botão para DESLOGAR da aplicação.
